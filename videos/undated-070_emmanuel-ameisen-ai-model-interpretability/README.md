## 简介

我们每天都在使用大语言模型，却很少有人真正知道它们内部发生了什么。模型究竟只是预测下一个 token，还是会提前规划、形成概念，甚至发展出类似“意识可及”的内部空间？

本期嘉宾 Emmanuel Ameisen 是 Anthropic 的可解释性（interpretability）研究员。他通过观察 Claude 内部的表征、激活值和计算回路，研究模型如何理解世界、跨语言处理概念、提前规划输出，以及为什么模型给出的推理过程不一定等于它真正进行的内部计算。

这场对话还讨论了扩展定律（scaling laws）、能力涌现、Golden Gate Claude、AI 对齐、模型意识与拟人化。最值得关注的是：AI 模型并不是被工程师逐条写出来的，而是在训练中“生长”出来的。理解这些内部机制，可能是判断模型是否可靠、是否在欺骗我们，以及未来能否安全部署更强 AI 的关键。

## 看点

1. 为什么造出一个 AI 模型，并不意味着我们理解它
2. “下一 token 预测器”为什么低估了模型的真实能力
3. Claude 如何形成跨语言共享的概念表征
4. 模型如何在输出前提前规划多个 token
5. 平滑的能力增长为什么看起来像突然发生的突破
6. Golden Gate Claude 如何揭示概念在模型内部的存在方式
7. 为什么只观察模型行为，无法彻底解决 AI 对齐问题
8. J-space 是否意味着模型拥有类似意识的内部工作空间
9. 什么时候用拟人化语言理解 AI 反而更准确
10. Jev 和 System 1 决策模型如何模拟快速直觉判断
