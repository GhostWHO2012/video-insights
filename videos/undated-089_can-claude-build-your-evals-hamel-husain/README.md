# 【中英双语】Claude 能直接帮你搭建 AI Eval 吗？| Hamel Husain

Anthropic 推出可帮助设计评测的 Claude Skill：它会询问要测什么、挑选目标、编写评判器，再让人检查结果。Hamel Husain 和 Isaac Flath 把它用在一组他们熟悉的租房助手数据上，现场测试 100 段真实对话，看看自动设计 eval 的流程是否经得起检验。
