# 别再抱怨 AI 写垃圾代码了 教你把代码变成黄金 | Lauren Tan

编码智能体能大量提交代码，但怎样让这些代码可靠？Lauren Tan 分享 Grok Bot 团队的做法：先改善智能体学习和工作的代码库，再把反复出现的错误写成架构约束、lint 规则和测试，最后让智能体运行应用、验证结果。

她用 Dune 框架、Electron 进程边界、功能地图和 UI 测试说明，为什么可靠的自动化依赖扎实的工程基础。Lauren 在演讲中称，她个人上个月提交约 3,000 个 PR；团队提交约 11,000 个 PR，被回滚的比例约为 0.5%。这些数字是团队实践的结果，视频更值得借鉴的是建立质量保障机制的顺序。
