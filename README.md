# Video Insights

AI 视频字幕、洞见目录、B站简介、中文时间轴与提纲图合集。

这个仓库用于公开同步每一期 B站视频的结构化资料，方便在评论区挂固定链接，也方便后续做网站检索和下载。

## 内容结构

- `videos/`：每期一个目录
- `videos/*/README.md`：该期洞见目录
- `videos/*/bilibili.md`：B站简介
- `videos/*/timeline.md`：中文字幕时间轴预览
- `videos/*/subtitles/`：中文在上字幕
- `videos/*/outlines/`：提纲图
- `data/episodes.json`：结构化索引数据
