## 简介

现在的大多数 AI 智能体，仍然主要通过纯文本和用户交流：用户发一条消息，智能体返回一大段文字。但真正有用的智能体，不应该只会“说”，还应该能把结果变成用户可以看、可以点、可以操作的界面。

DeepLearning.AI 的这门课程《用生成式 UI 构建交互式智能体》，由 CopilotKit 联合创始人 Atai Barkai 讲授。课程会带你构建一种全栈智能体界面：智能体可以按需渲染图表、表单、按钮、白板和交互式组件，而不是只返回普通文本。

课程围绕 CopilotKit 和 AG-UI 协议展开，覆盖从手工控制的组件，到由智能体组合的声明式布局，再到基于 MCP Apps 的开放式体验。最终，你会完成一个画布应用，让智能体能和用户围绕共享数据一起工作，并构建出一个可用于生产环境的全栈智能体应用。

## 看点

1. 从纯文本智能体走向可视化、可交互的智能体界面
2. 为什么 AI 应用不能只返回大段文字
3. 生成式 UI 如何让智能体按需渲染表单、图表、按钮和画布
4. CopilotKit 与 AG-UI 如何连接智能体、前端组件和应用状态
5. 如何从手工控制组件走向声明式布局和开放式体验
