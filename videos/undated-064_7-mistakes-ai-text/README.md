# 7 个一眼暴露“AI 味”的写作错误，以及如何修正｜Jason

原视频：7 Mistakes That Scream “AI TEXT” (and How to Fix It)

B站：https://www.bilibili.com/video/BV1AYhJ63E95/

## 简介

Jason 把 AI 文本常见的“AI 味”拆成 7 个可识别的问题：比喻过载、解释过度、宣传腔、同义词乱换、假高级词、固定句式和机械排比，并给出具体修法。

## 看点

1. AI 文本为什么会顺滑却空洞
2. 如何把文字拉回具体场景和真实声音
3. 如何用 Claude 技能逐项清理 AI 破绽
4. 为什么最终判断必须回到作者手里
