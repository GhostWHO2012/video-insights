# AI 为什么总写出低质文本？如何找回你的真实文风｜In-Ear Insights

原视频：In-Ear Insights: Why Does AI Write Slop?

B站：https://www.bilibili.com/video/BV1uahU6eEos/

## 简介

Christopher S. Penn 和 Katie Robbert 讨论 AI 为什么会把有个人特色的文字写成重复、套路化的“低质 AI 文本”，并介绍如何量化个人文风、建立写作蓝图，再把这些指标写进提示词和编辑流程。

## 看点

1. AI 味来自哪些重复的语言模式
2. 如何测量个人文风和写作指纹
3. 如何用提示词与编辑流程控制模型输出
4. 为什么 AI 不是作者声音的替代品
