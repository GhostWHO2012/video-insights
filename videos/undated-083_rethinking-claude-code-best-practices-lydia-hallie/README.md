# 模型进化后 我们该如何与 Agent 协作 | Lydia Hallie

模型越来越强，过去为 Claude Code 写下的许多“最佳实践”，可能反而在限制它。以前，开发者需要守着一两个会话，反复纠正模型、批准命令；现在，一个人可以让多个 Agent 长时间并行工作。人不再盯着每一步，该怎样保证它们做对事、不越界？
