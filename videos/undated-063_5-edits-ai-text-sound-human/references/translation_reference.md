内容简介：
这个视频讲的是如何使用 LLM 提高写作效率，同时避免文字读起来像模型生成的“AI 腔”。作者基于过去两年编辑大量 AI 辅助稿件、课程内容、视频脚本和书稿的经验，总结出 AI 文本最容易暴露的结构问题和语言习惯。

重点不是简单要求模型“别像 ChatGPT”，而是通过更明确的提示词、更好的段落结构、更少的套话、更具体的例子，以及最后一轮人工编辑，让 AI 初稿变成可以发布、可以署名、也保留作者文风的文本。

翻译风格：
整体用自然中文，不要太书面化。
human 在这里不要翻成“人类化”，优先翻成“像人写的 / 真人写作 / 更自然”。
AI text 可以翻成“AI 文本”或“AI 生成文本”。
AI slop 建议翻成“低质 AI 文本”或“AI 垃圾内容”。
voice 在写作语境里翻成“文风 / 作者声音”，不要机械翻成“声音”。
generic 多数情况翻成“泛泛而谈 / 套路化 / 没有个性”。
prompt 统一翻成“提示词”。
edit pass 翻成“一轮编辑 / 一轮修改”。
rewrite 翻成“重写”。
lightly edit 翻成“轻度编辑 / 稍作修改”。
human pass 翻成“人工检查 / 人工润色”。
mechanical slop 翻成“机械化的低质内容 / 机械感很重的废话”。

翻译注意：
不要把 sound human 翻成“听起来像人类”，应翻成“读起来像人写的”。
不要把 voice 都翻成“声音”，写作语境里一般是“文风”。
不要把 slop 轻描淡写成“内容”，它带贬义。
不要把 generic 一律翻成“通用”，这里更多是“泛泛而谈、套路化、没个性”。
不要把 prompt 翻成“咒语”或“指令”，统一用“提示词”。
字幕里涉及课程广告、订阅频道、Discord 等结尾推广，可以正常翻译，但不要扩大成正文重点。
