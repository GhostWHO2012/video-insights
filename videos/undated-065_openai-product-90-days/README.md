# 别再规划 2027：OpenAI 如何以 90 天为周期打造产品｜Tara Seshan、Nan Yu

原视频：Stop planning for 2027: how OpenAI builds product 90 days at a time | Tara Sesha and Nan Yu (OpenAI)

B站：https://www.bilibili.com/video/BV1nTHp6pE1X/

## 简介

OpenAI 的 Tara Seshan 与 Nan Yu 从一个尚不完美的产品开关谈起，讨论模型快速进步时，产品团队怎样决定何时发布、何时调整，以及怎样让用户跟上能力变化。对谈涉及智能体分工、权限与记忆、第三方工具、任务最后一公里、产品评测和 60–90 天规划周期。

## 看点

1. 为什么 AI 产品适合尽早交给真实用户验证
2. 单一智能体与多个专用智能体各有什么代价
3. 为什么完成任务的最后一公里比演示能力更重要
4. 产品负责人如何把用户问题转化为模型评测
5. 为什么 OpenAI 更关注未来 60–90 天
