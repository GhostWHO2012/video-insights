# 来自Snap与Discord前产品负责人的 90 分钟无滤镜产品建议 | Peter Sellis

做了七年 Snapchat 首位产品经理，又带领 Discord 产品团队，Peter Sellis 这次不带公关稿，直接谈他在消费产品一线做过的选择：团队里谁该有决策权，怎样管理能力突出却不按常规工作的成员，Snap 的广告为什么难做，以及 Discord 如何靠重新服务核心用户找回增长。

这期的价值在于，他不只讲“应该怎么做”，也坦率分析哪些判断没能奏效。从产品品味、系统思维，到 ChatGPT 的广告与用户信任，适合做产品、增长和团队管理的人观看。
