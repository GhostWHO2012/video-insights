# 新一代全栈设计师 | Marvin Schwaibold

当 AI 已经能写代码，设计师的工作会发生什么变化？Shopify 产品设计工作室负责人 Marvin Schwaibold 与 Y Combinator 的 Aaron Epstein 分享了自己的工作流程：从在 Figma 中梳理想法，到使用 Codex、Claude Code 做出可运行的原型，再通过实际操作反复打磨交互。

本期既有 Shopify 管理后台和 AI 助手 Sidekick 的设计案例，也有用着色器重现草地、经过91次尝试打磨轮播组件的个人实验。后半部分通过六个网站的现场点评，具体讨论如何突出页面目标、展示产品价值，以及避免让动画、标签页和滚动效果妨碍用户。

## 本期看点（根据内容整理）

1、设计师亲自做出原型，在手机和电脑上测试交互。
2、AI 承担更多实现工作，设计师负责筛选结果与控制质量。
3、用 Figma 草图向 Codex 解释难以用文字描述的交互。
4、拆解参考、检查底层结构、开放参数，逐步打磨演示效果。
5、通过清晰的页面目标、信息层级和按钮主次，帮助用户理解产品。
6、用真实演示传达价值，减少标签页隐藏信息和滚动劫持带来的障碍。
