# 制作产品发布视频的正确方式｜Farza Majeed

产品发布视频不一定需要昂贵的设备、精致的广告片或声势浩大的发布日。Hey Clicky 创始人、Buildspace 前创始人 Farza Majeed 与 Y Combinator 的 Aaron Epstein 讨论了另一种思路：把每一次产品演示都当成一次小型发布，用真实、直接、持续的视频让用户看见产品价值。

本期从 Hey Clicky 的发布案例讲起，具体拆解怎样从开场钩子倒推脚本，如何让写好的台词听起来像即兴表达，怎样判断视频是否真的吸引人，以及播放量、下载量、留存和转化之间的区别。Farza 还分享了不同平台的内容策略、设备与收音选择、叙事节拍、招聘影像创作者的原因，以及连续发布 30 天的实践挑战。
