# B站发布资料

## 标题

用 Claude Code 做好 AI 评估的 5 个步骤｜Shreya & Hamel

## 简介

这期 Peter Yang 邀请 Shreya Shankar 和 Hamel Husain，现场审查一套 AI skills 的评估体系，演示如何用 Claude Code / Codex 把真实反馈、失败案例和人的判断力转成可复用的 evals。

核心看点是：好的 AI 评估不是让模型凭空写规则，而是先看真实数据、真实输出和真实失败，再把人的品味、判断力和具体标准外化出来。
