# 你的 SKILL.md 里 70% 的内容模型早已掌握 | Nikolay Petrov

给 SKILL.md 加一条指令只要几秒，删掉一条却很难判断会不会影响任务结果。英特尔的 Nikolay Petrov 分享了一套评测方法：把技能拆成可单独检验的知识点或操作要求，让同一个模型在加载和未加载技能的情况下各答一遍，找出哪些内容是模型已经会的，哪些提供了新信息，哪些会让模型答得更差。
