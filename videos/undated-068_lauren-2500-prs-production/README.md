# 如何在一个月内将 2,500 个 PR 推上生产环境｜Lauren Tan

原视频：Here's How I Shipped 2,500 PRs Last Month to Production

B站：https://www.bilibili.com/video/BV1twpc6gEXS/

## 简介

Lauren Tan 分享了如何构建一套高信任度的 Agent 工程体系。她用“米其林厨房”描述理想的开发环境：代码库、工具、规则和反馈系统共同组成基础设施，让 Agent 在无人逐条监督时仍能交付可验证的高质量成果。

## 看点

1. 如何从少量 Agent 扩展到约 100 个 Agent
2. Control Glass 如何让 Agent 操作并验证应用
3. feature map 与 pstack 如何沉淀工程知识
4. 五级纠错体系怎样让正确行为成为默认选择
5. Grok Bot 如何形成自动响应事件的外循环
