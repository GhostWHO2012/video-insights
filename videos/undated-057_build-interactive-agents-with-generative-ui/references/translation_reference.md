## 简介译文

现在的大多数 AI 智能体，仍然主要通过纯文本和用户交流：用户发一条消息，智能体返回一大段文字。但真正有用的智能体，不应该只会“说”，还应该能把结果变成用户可以看、可以点、可以操作的界面。

DeepLearningAI 的这门短课程《用生成式 UI 构建交互式智能体》，由 CopilotKit 联合创始人 Atai Barkai 讲授。课程会带你构建一种全栈智能体界面：智能体可以按需渲染图表、表单、按钮、白板和交互式组件，而不是只返回普通文本。

课程围绕 CopilotKit 和 AG-UI 协议展开，覆盖从手工控制的组件，到由智能体组合的声明式布局，再到基于 MCP Apps 的开放式体验。最终，你会完成一个画布应用，让智能体能和用户围绕共享数据一起工作，并构建出一个可用于生产环境的全栈智能体应用。

## 易误译点

“all UI is becoming AI” 建议译为：所有用户界面都正在被 AI 重塑。  
“walls of text” 建议译为：大段文字，不要直译成“文字墙”。  
“show the results back to the user” 建议译为：把结果以界面形式呈现给用户。  
“mediated by agents” 建议译为：由智能体居中协调 / 通过智能体完成。  
“command line MS-DOS era” 是类比，指当前很多智能体还停留在命令行式交互阶段。  
“Windows and Mac era changed that” 指图形界面让计算机从早期用户工具变成大众可用的应用平台。
