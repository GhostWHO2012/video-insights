# 用 Astra、DiffUI 和 Codex 制作惊艳 3D 落地页｜Meng To

原视频：I recorded a 41-minute tutorial on how I use Astra to create insane three.js websites in Codex

B站：https://www.bilibili.com/video/BV1sJYN66EoY/

## 简介

这期教程展示了 Meng To 如何从 DiffUI 的视觉探索开始，把设计方案、提示词和参考信息交给 Codex，再用 Three.js、图像生成和 3D skills 完成可交互的网页。

## 看点

1. DiffUI 如何帮助设计者在编码前快速发散
2. Copy for agent 如何传递完整设计上下文
3. 如何用图层、材质、光照和动画制作 3D 网页
4. 如何建立可复用的 3D skills 工作流
