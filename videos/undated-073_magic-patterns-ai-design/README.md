# 如何在 AI 设计泛滥的时代脱颖而出？｜Alex Danilowicz

AI 已经能快速生成网站和交互原型，但怎样让设计真正帮助用户理解产品？Magic Patterns 联合创始人 Alex Danilowicz 演示新版画布 MagicOS，分享团队如何将提示词、图片、需求文档和组件用于设计探索。

后半段现场点评 Ego、Sentient OS、Cerenovus 和 Slashy 四个网站，讨论首屏文案、主要按钮、动画、滚动劫持、产品演示和信任建设。最后谈设计品味、用户反馈与发布速度。
